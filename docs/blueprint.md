# **App Name**: Profolio

## Core Features:

- Animated Page Transitions: Smooth, liquid-like transitions between different sections of the portfolio (Home, Projects, About, Contact) to enhance user experience.
- Dynamic Content Loading: Load project details and content dynamically using Next.js, creating a seamless and responsive browsing experience.
- Interactive Animations: Incorporate interactive animations triggered by user actions (e.g., scrolling, hovering) to add a layer of engagement and visual interest.
- About Page Animation: Display the 'About' information inside a slowly appearing, fading-up dialog when a cross icon is clicked, and ensure smooth animations.
- Personalized Opening Statement Generation: Use a tool that analyzes the visitor's LinkedIn profile URL (provided by the user) to generate a tailored opening statement that resonates with their professional background and interests.
- Project Showcasing: Showcase all the project with all relevant links to git, website and others, and generate responsive layout for projects to increase readablity.
- Contact Information: Create easy to find information to quickly connect with visitor.

## Style Guidelines:

- Primary color: HSL analysis suggests a soft sky-blue hue for the 'liquid' aesthetic. Use #89CFF0 (RGB) for a calming, inviting feel. The color aims to evoke a sense of tranquility, similar to clear water.
- Background color: Choose a light, desaturated version of the primary hue. Use #E5F5FF (RGB) for a clean backdrop that enhances the liquid effect.
- Accent color: Introduce a contrasting but analogous color such as #A0D6B4 (RGB), a pale, gentle green, to draw attention to key elements without disrupting the calm aesthetic.
- Font pairing: Use 'Space Grotesk' (sans-serif) for headlines and short amounts of body text, paired with 'Inter' (sans-serif) for longer body text to ensure readability. 'Space Grotesk' has a slight tech feel appropriate for a modern portfolio, while 'Inter' provides a neutral tone for sustained reading.
- Incorporate simple, line-based icons to maintain a minimalist aesthetic, using the primary color (#89CFF0) for the icons.
- Implement a fluid, responsive layout with generous spacing to enhance the sense of openness and clarity.
- Utilize subtle animations, like fades and parallax scrolling, to add depth and interactivity without overwhelming the user.
